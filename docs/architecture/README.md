# Architecture Docs – Tooling Notes

These documents use **Mermaid diagrams** embedded in Markdown.

## Rendering

- **GitHub** renders Mermaid natively (no setup required).
- **VS Code** requires the following extensions:
  - _Mermaid Markdown Syntax Highlighting_
  - _Markdown Preview Mermaid Support_

## Rules

- All diagrams must be inside fenced `mermaid` code blocks.
- Do not replace diagrams with images or screenshots.
